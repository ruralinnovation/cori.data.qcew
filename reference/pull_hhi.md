# Pull Herfindahl-Hirschman Index of employment concentration

Pull Herfindahl-Hirschman Index of employment concentration

## Usage

``` r
pull_hhi(years, staging_dir = "data/qcew")
```

## Arguments

- years:

  Integer vector. Years to pull.

- staging_dir:

  Character. Local staging directory. Default: `"data/qcew"`.
