# Download BLS QCEW county high-level zip file for a single year

Download BLS QCEW county high-level zip file for a single year

## Usage

``` r
download_qcew(year, staging_dir = "data/qcew")
```

## Arguments

- year:

  Integer. Year to download (1990 or later).

- staging_dir:

  Character. Directory to save zip files. Default: `"data/qcew"`.
