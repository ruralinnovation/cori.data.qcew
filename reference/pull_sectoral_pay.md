# Pull employment-weighted average annual pay by CORI super-sector

Pull employment-weighted average annual pay by CORI super-sector

## Usage

``` r
pull_sectoral_pay(years, staging_dir = "data/qcew")
```

## Arguments

- years:

  Integer vector. Years to pull.

- staging_dir:

  Character. Local staging directory. Default: `"data/qcew"`.
